## 四、逆运动学 IK（全解法）

> 湃特纳、零次方、赛博格均深挖 IK；需能按「解法分类 → 流程 → 适用场景」完整讲清。

### 4.1 解法分类总览

| 类别 | 代表方法 | 面试常问 |
|------|----------|----------|
| **解析/几何法** | Pieper 型 6DOF、臂角法 7DOF | 流程、多解、限位 |
| **数值迭代法** | Jacobian 伪逆、阻尼最小二乘 DLS、Levenberg-Marquardt | 收敛条件、步长、阻尼 |
| **优化法** | NLopt、CasADi + Pinocchio、非线性约束 IK | 约束处理、冗余零空间 |
| **库封装** | KDL LMA、Trac-IK、MoveIt `/compute_ik` | 与自研 IK 如何配合 |

### 4.2 按解法展开的面试问题

| # | 高频问题 | 典型追问 |
|---|----------|----------|
| 4.1 | IK 主要有哪几种典型解法？各自优缺点和适用场景？ | 解析快但结构受限；数值通用但慢 |
| 4.2 | **解析几何法**解 6DOF 机械臂的详细流程？ | 腕部分离、求肩肘、求腕角 |
| 4.3 | **臂角法（Arm Angle）**的详细流程？冗余参数 ψ 物理含义？ | 固定 q4 或 ψ 后降维求解 |
| 4.4 | **Jacobian 迭代法**一步怎么算？伪逆、DLS、LM 区别？ | Δq = J⁺Δx + 零空间项 |
| 4.5 | **优化 IK** 目标函数和约束一般怎么设？ | 位姿误差 + 关节限位 + 避障 + 冗余正则 |
| 4.6 | KDL / Trac-IK / MoveIt IK 在规划管线里扮演什么角色？ | 笛卡尔目标 → goal_state |
| 4.7 | IK 失败时 MoveIt 返回什么？工程上怎么处理？ | NO_IK_SOLUTION、换 seed、放宽姿态 |
| 4.8 | 数值 IK 初始值 seed 怎么选？ | 上一帧、最近 home、多 seed 并行 |
| 4.9 | 解析 IK 和数值 IK 如何组合成生产级方案？ | 解析主路径 + 数值 fallback |
| 4.10 | 既然有 Pinocchio/KDL，为什么还要自研臂角法？ | 7DOF 定制、延迟、可控多解策略 |

**关联场次：** 赛博格 §6 · 湃特纳 §1 · 零次方 §1 · Idata §3
