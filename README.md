## 内容分层规则

| 层级 | 职责 | 维护原则 |
|------|------|----------|
| **L0 原始** | 面试原题、公司信息 | 面试后追加，不修改历史 |
| **L1 理论** | 概念、架构、算法 | 读论文 / 跟新模型时更新 |
| **L2 实践** | 项目细节、超参、踩坑 | 项目里程碑后更新 |
| **L3 面试** | 可口述答案、专题索引 | 答案以「面试知识储备」为准，专题只保留话术 |

**Canonical 规则**：同一知识点只在一处完整展开——理论看 L1，工程 Q&A 看 L3 知识储备，项目数字看 L2。

---

## 维护工作流

1. **面试后** → `面试复盘.md` 记原题 → `面试知识储备.md` 写标准答案 → 专题文档补链接
2. **项目节点** → 更新 L2 实践文档的「效果 / 踩坑 / 若重做」
3. **每月** → 检查 README 索引、文档元信息中的「更新」日期、相对链接
