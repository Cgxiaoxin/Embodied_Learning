## 一、本篇定位

你在 03 里已经走过「坐标系 → 位姿 → 正逆解 → 雅可比 → 控制链路」的完整路径。动力学笔记从本篇起不再展开 DH 表格或 IK 细节，只回答：**哪些运动学对象会在后续方程里反复出现，以及它们如何与力/力矩对接。**

## 二、位姿：旋转矩阵 / 四元数 / 齐次变换

**旋转矩阵** \(R \in SO(3)\) 把向量从一个坐标系转到另一个，复合用矩阵乘法，数值稳定、求逆方便；缺点是 9 个数冗余、欧拉角提取时有万向节锁。适合离线标定、多坐标系链式变换。

**四元数** \(q = [w, x, y, z]^\top\) 用 4 个数表旋转，无万向节锁、插值（slerp）平滑，是 IMU、VLA 姿态输出、实时滤波的常见选择；需注意双覆盖（\(q\) 与 \(-q\) 同姿）与归一化。

**齐次变换** \(T = \begin{bmatrix} R & p \\ 0 & 1 \end{bmatrix}\) 把旋转与平移合成 4×4 矩阵，正运动学就是沿关节链连乘 \(T\)。DH 参数表、URDF/SRDF、仿真里连杆树，底层几乎都是齐次变换。

**何时用**：链式 FK/标定用 \(T\)；策略或传感器给姿态增量时常用四元数；需要显式正交约束或求 \(R^{-1}=R^\top\) 时用旋转矩阵。03 中有更完整的对比与 VLA 落地注意点。

## 三、正运动学与 DH

**正运动学（FK）**：给定关节角 \(q\)，求末端位姿 \(x\)（或 \(T_{base}^{ee}\)）。串联臂就是连杆变换连乘。

**DH 参数**：用 \((a, \alpha, d, \theta)\) 描述相邻连杆关系。**标准 DH** 与 **改进 DH（MDH）** 的差别在连杆坐标系附着方式与参数表列顺序——同一机械臂两种表都对，但混用会错。工程上跟厂商/URDF 约定一致即可；一句话：**标准 DH 常见于教材，改进 DH 常见于 Kuka 等工业臂文档。**

FK 本身不进入动力学方程，但 \(q \mapsto x\) 的映射决定了后面 \(J(q)\) 的定义域；03 第五节有正解流程与示例。

---

## 四、逆运动学：解析 vs 数值

**逆运动学（IK）**：给定目标位姿，求 \(q\)。**解析 IK** 对特定构型（6R 腕部解耦等）有闭式解，快、可枚举多解；**数值 IK**（Jacobian 迭代、QP、CasADi 等）通用但依赖初值，可能陷入局部最优或奇异附近发散。

动力学里 IK 不是主角，但力控与任务空间控制常先在笛卡尔空间定 \(F\) 或 \(\ddot x\)，再经 \(J\) 或 IK 回到关节。部署时「模型输出末端增量 → IK → \(\tau\)」链路与 03 第六节动作空间设计直接相关。

## 五、微分运动学：几何雅可比 vs 解析雅可比

末端 twist（线速度 + 角速度）与关节速度的关系：

\[
\dot x = J(q)\,\dot q
\]

**几何雅可比**：由连杆几何与当前 \(q\) 直接构造（叉乘列），与 03 中直觉一致。**解析雅可比**：对 FK 输出 \(x(q)\) 求偏导，便于自动微分或与学习框架对接。二者在正确建模下应一致；实现混用坐标系（世界系 vs 工具系）时最容易出错。

**奇异位形**：\(\det J\)（或最小奇异值）接近 0 时，某些末端方向无法瞬时实现，或关节速度需求爆炸。力控在奇异附近也会放大 \(\tau = J^\top F\)。03 5.4–5.5 节有奇异直觉与排查建议。

## 六、进入动力学的两个接口公式

后续各篇会在关节空间写 \(M\ddot q + C\dot q + G = \tau + \tau_{ext}\)，在任务空间写 \(\Lambda \ddot x + \mu + p = F\)。连接两者的桥梁就是 \(J(q)\)：

| 映射 | 公式 | 工程含义 |
|------|------|----------|
| 速度 | \(\dot x = J(q)\,\dot q\) | 关节速度 → 末端 twist；笛卡尔阻抗、操作空间控制、VLA 末端增量控制都依赖此线性化 |
| 静力/力矩 | \(\tau = J^\top F\) | 末端 wrench \(F\)（力+力矩）↔ 关节力矩；纯力控、接触力映射、重力补偿后的任务力分配 |

**说明**：\(\tau = J^\top F\) 是虚功原理下的**静力/拟静力**关系；含加速度时还有 \(M, C, G\) 与操作空间惯量 \(\Lambda = (J M^{-1} J^\top)^{-1}\)（见 06 篇）。但即便在完整动力学里，\(J\) 与 \(J^\top\) 仍是出现频率最高的两个接口。

## 小结

- 位姿用 \(R\)/四元数/\(T\) 各有场景；FK/DH/IK 的详述与 VLA 动作空间见 [03-机器人控制与坐标系基础](../03-机器人控制与坐标系基础.md)。
- 动力学系列本篇只固化两条接口：**\(\dot x = J(q)\dot q\)**（速度）与 **\(\tau = J^\top F\)**（静力映射）。
- 奇异位形与雅可比坐标系对齐是力控部署的常见坑；排查请回 03 雅可比一节。
