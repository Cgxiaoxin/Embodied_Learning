## 一、为什么接触动力学对 VTLA/视触觉关键

**接触动力学（contact dynamics）** 研究刚体（或软体）在约束与摩擦下的相互作用力。对机器人学，它解释：为何同样到位姿，**法向力/滑移**可以完全不同；为何仿真里「捏住了」真机却滑落。

标准关节方程（[04 篇](./04_dynamics_equation_properties.md)）：

\[
M(q)\,\ddot q + C(q,\dot q)\,\dot q + G(q) = \tau + \tau_{ext}
\]

接触不改变 \(M,C,G\)，而是通过 **\(\tau_{ext}\)** 进入右端。[07 篇](./07_dynamics_based_control.md) 的阻抗/混合控制设定 \(K,D\) 与力/位子空间，但**环境能施加多大的 \(F\)、是否滑移**，由接触模型与摩擦律决定——二者必须在同一物理图景下理解。

### VTLA / 视触觉桥接（短）

视触觉（VTLA）管线中，**视觉**给全局位姿与物体几何，**触觉**给局部压力、剪切与滑移线索；策略或 VLA 常输出笛卡尔增量 \(\Delta x\) 或抓取指令。动力学层需要回答三个对齐问题：

| 层次 | 触觉 / 策略侧 | 动力学侧 |
|------|---------------|----------|
| 观测 | 压力图、触觉 RGB、滑移事件 | 接触点法向/切向力 \(F_n, F_t\) |
| 方程 | 「轻推」「握紧」语义 | \(\tau_{ext} = J^\top F\)，与 \(\tau\) 并列 |
| 控制 | 事件驱动柔顺（见 07） | 互补约束 + 摩擦锥：能否静止、何时滑 |

**Sim2Real 典型落差**：仿真用无限刚性点接触、无摩擦迟滞，策略学到「顶到就停」；真机有柔顺、摩擦与力闭合不足 → 力峰值、滑移与抓取失败与训练分布不一致。建立 **触觉观测 ↔ \(F\) ↔ \(\tau_{ext}\) ↔ 约束/摩擦** 的词汇，是 07（控制）与 09（仿真/估力）之间的必要一环。

```
VLA / 策略：Δx, 抓取宽度
        ↓
阻抗 / 混合（07）：K, D, S
        ↓
接触模型 + 摩擦（本篇）：F_n, F_t, 滑移？
        ↓
τ_ext = J^T F → M q̈ + … = τ + τ_ext
        ↑
触觉：压力/滑移 → 估计 F̂（09 篇）
```

## 二、接触模型：点接触与软接触

真实接触是**有限面积**上的压力分布；机器人学与仿真常用两类抽象。

### 点接触（point / hard contact）

假设两刚体在一点（或少量点）接触，**法向不可穿透**：

\[
\phi(q) \ge 0 \quad \text{（间隙 /  signed distance）}
\]

\(\phi=0\) 时接触活跃；\(\phi>0\) 分离。法向接触力 \(f_n \ge 0\) 仅当 \(\phi=0\) 时可非零（**单边约束**）。点接触忽略面积、应力集中与材料变形，但：

- 与 **力闭合、摩擦锥** 分析兼容（抓取力学经典框架）；
- MuJoCo、Drake 等默认多接触为**点/面离散点**；
- 计算轻，适合 MPC、WBC-QP 与大规模仿真。

**局限**：高刚度数值仿真易「抖动」；无法直接产生触觉传感器上的**压力分布**——需额外映射或软接触。

### 软接触（compliant / spring-damper）

用**法向弹簧阻尼**近似界面柔顺：

\[
f_n = k_n\,\max(0,\,-\phi) + d_n\,\dot\phi
\]

或更一般的 **Hertz / Hunt–Crossley** 等非线性律。穿透 \(\phi<0\) 时产生恢复力；**允许微小穿透**，换数值稳定与连续可微（利于可微仿真、梯度优化）。

| 对比 | 点接触（硬） | 软接触 |
|------|--------------|--------|
| 穿透 | \(\phi\ge 0\) 严格 | 小穿透产生力 |
| 仿真稳定性 | 需求解器/互补 | 常更平滑 |
| 物理 | 刚体理想化 | 近似材料/涂层柔顺 |
| 触觉 | 需从 \(f_n\) 外推分布 | 可与「弹性体」传感器模型衔接 |
| 典型用途 | 抓取力闭合分析、刚体 MPC | Sim2Real 柔顺、可微物理 |

**工程选择**：力控/抓取分析多用**点接触 + 摩擦锥**；训练策略、域随机化时常在仿真中加**软接触或接触刚度随机化**（[09 篇](./09_sim_tools_and_learning.md)）。VTLA 中，GelSight 等传感器本身有弹性层——软接触直觉与「触觉图像 ↔ 局部变形」一致。

### 多接触与接触流形

多指抓取、桌角支撑 → **多个接触点** \(\phi_i(q)\)，各自 \(f_{n,i}, f_{t,i}\)。约束构成**接触流形**上的混合：部分点分离、部分闭合、部分滑移。WBC 与 QP 常把每个接触写成 **摩擦锥内的 wrench**（见第五节）。

## 三、摩擦：库仑与 LuGre

切向摩擦力决定**能否静摩擦保持、何时滑移**——对视触觉中的滑移检测与抓取稳定性至关重要。

### 库仑摩擦（Coulomb）

**静摩擦**（无相对滑动，\(\dot s = 0\)）：

\[
\|f_t\| \le \mu\, f_n, \quad f_n \ge 0
\]

**动摩擦**（滑移，\(\dot s \neq 0\)）：

\[
f_t = -\mu_d\, f_n\, \frac{\dot s}{\|\dot s\|}
\]

\(\mu\)（静摩擦系数）、\(\mu_d\)（动摩擦系数）为材料/表面对参数；常 \(\mu_d \le \mu\)。几何上，\((f_n, f_t)\)  allowable 集为**摩擦锥**（3D 接触为圆锥，2D 为楔形）。

| 优点 | 局限 |
|------|------|
| 形式简单，与互补约束天然配套 | **瞬时切换**静↔动，仿真不连续 |
| 力闭合、抓取分析标准假设 | 无速度相关过渡，高速行为失真 |
| 参数少（\(\mu\)），易域随机化 | Stribeck、预滑动无法刻画 |

**适用**：抓取力闭合判断、准静态推/拉、QP 摩擦锥约束、教学与大规模 RL 仿真（MuJoCo `friction` 滑移维度即库仑型）。

### LuGre 摩擦（动态摩擦模型）

**LuGre 模型**引入**鬃毛（bristle）**状态 \(z\)，用内部状态模拟接触面微观变形：

\[
\dot z = \dot s - \frac{\|\dot s\|}{g(\dot s)}\, z
\]

\[
f_t = \sigma_0\, z + \sigma_1\, \dot z + \sigma_2\, \dot s
\]

\(g(\dot s)\) 随速度变化，可再现 **Stribeck**（低速时 \(\mu\) 更小 → 易滑）。静摩擦时 \(z\) 蓄能；滑移时 \(z\) 松弛 → **连续过渡**，减轻库仑切换带来的数值抖振。

| 优点 | 局限 |
|------|------|
| 更贴近真机低速粘滑、预滑动 | 参数 \((\sigma_0,\sigma_1,\sigma_2, g)\) 需辨识 |
| 利于力控与滑动检测仿真 | 每接触多状态，成本高 |
| 与触觉「即将滑移」现象一致 | 大规模并行 RL 中较少默认启用 |

**适用**：精细力控、滑动检测算法验证、Sim2Real 中**摩擦动态**敏感任务；与视触觉中「滑移前剪切力上升」的观测对照。若仅关心**能否抓稳**，库仑 + 力闭合往往足够；若关心**何时、以多快速度滑**，LuGre 或更简 Stribeck 更合适。

### 与仿真的对应（预告）

- **MuJoCo**：库仑摩擦在切向约束上与 `solref`/`solimp` 接触阻抗配合；LuGre 需自定义或外力回调。
- **Drake**：显式摩擦锥 + 互补或 SDP；支持多种摩擦公式。
- **Pinocchio**：动力学核不内置接触求解；接触力常由外部仿真器或 QP 提供，再映回 \(\tau_{ext}\)。

实现细节与触觉估力见 [09 篇](./09_sim_tools_and_learning.md)。

## 四、互补性约束与仿真直觉

硬点接触下，法向力与间隙、切向力与滑移速度之间满足 **互补性（complementarity）**——「力只在接触时存在，接触时法向只能推不能拉」。

### 单边约束与互补（直觉）

对每个接触点，记法向间隙 \(\phi\)、法向力 \(f_n \ge 0\)、法向相对速度 \(v_n = \dot\phi\)（分离为正）。理想无耗散接触：

\[
\phi \ge 0, \quad f_n \ge 0, \quad f_n \cdot \phi = 0 \;\text{或}\; f_n \cdot v_n = 0
\]

**互补对** \((\phi, f_n)\) 或 \((v_n, f_n)\)：二者至多一个「严格在边界外」——要么分离（\(\phi>0, f_n=0\)），要么接触且 \(f_n\) 阻止穿透。加入摩擦后，切向满足**摩擦锥互补**（库仑锥内或滑移时力在锥边界上）。

这不是本篇要手推的 KKT 系统，但读者应建立直觉：

```
分离：  φ > 0  →  f_n = 0
接触：  φ = 0  →  f_n ≥ 0 阻止进一步穿透
滑移：  f_t 在摩擦锥边界，与切向速度方向相反
```

### 与 LCP / NCP

离散时间仿真将 \(\ddot q\) 与接触冲量联立，常化为 **线性互补问题（LCP）** 或 **非线性互补问题（NCP）**：未知量含 \(f_n, f_t\) 与接触加速度/冲量，约束含 \(\phi\ge 0\)、摩擦锥、互补条件。MuJoCo 的约束求解器、Drake 的 `ComplementarityConstraint` 均属此类族。

| 工具 | 接触求解思路（高层） |
|------|----------------------|
| **MuJoCo** | 软约束 + 迭代求解；多接触点 `condim`（1 法向 / 3 含摩擦 / 6 含扭转） |
| **Drake** | 硬互补或 SDP 松弛；显式摩擦锥 |
| **Pinocchio** | 正向动力学 + 外部接触力；常与 MuJoCo/自研 QP 耦合 |
| **Bullet / Isaac** | 类似惩罚或 LCP；参数调参影响 Sim2Real |

**为何 VTLA 读者需要懂互补**：触觉给出「已接触」的观测，但仿真器用 \(\phi\) 与 \(f_n\) 的互补决定**是否真有法向力**；对齐不当会出现「视觉已贴合、仿真零力」或「穿透爆炸」。09 篇讨论如何用**接触刚度随机化、软接触、摩擦域随机**缓解。

本篇止于**词汇与直觉**；不展开 Jacobian 约束 \(\dot\phi = J_c \dot q\)、冲量映射与具体求解器参数。

## 五、力闭合与抓取稳定性

**抓取（grasp）** 不仅是「夹爪闭合」，而是多接触力能否**平衡外负载**且**抵抗扰动**。

### 力闭合（force closure）

设 \(m\) 个接触点，每点法向 \(n_i\)、切向基 \(t_{i,1}, t_{i,2}\)，接触力

\[
F_i = f_{n,i}\, n_i + f_{t,i,1}\, t_{i,1} + f_{t,i,2}\, t_{i,2}, \quad f_{n,i} \ge 0,\; (f_{t,i,\cdot}) \in \mu_i f_{n,i}
\]

若对**任意**作用在物体上的外 wrench \(w_{ext}\)（在合理有界集内），存在一组 \(\{F_i\}\) 在摩擦锥内使 \(\sum F_i + w_{ext} = 0\)（静力平衡），则称该接触构型 **力闭合**（对平面抓取常简化为：**摩擦锥的正张成包含外力空间**）。

**直觉**：手指从多个方向「卡住」物体；即使未知外力方向，也能通过调节各指法向力与摩擦利用平衡。**与形闭合（form closure）** 不同：形闭合靠几何约束，力闭合依赖 **\(\mu > 0\)**——光滑面、低摩擦时形闭合可能成立而力闭合不成立。

| 因素 | 对力闭合的影响 |
|------|----------------|
| 接触点数 / 分布 | 越多、越均匀，越易闭合 |
| \(\mu\) | 过低则切向承载不足，易滑 |
| 接触法向朝向 | 法向需「指向」物体内部（\(f_n\ge 0\) 可行） |
| 负载方向 | 重力沿指法向分量需被摩擦与法向力承担 |

### 抓取稳定性（准静态）

**稳定性**常指：小扰动下接触不破裂、物体不滑、不脱落。准静态下：

1. **平衡**：\(\sum_i F_i + w_{gravity} = 0\)（及力矩平衡）；
2. **摩擦可行**：各 \(F_i\) 在库仑锥内；
3. **扰动抵抗**：对微小位移/力扰动，存在满足约束的 \(F_i\) 调整（与力闭合或刚度相关）。

**柔顺手指 / 软接触**改变有效 \(\mu\) 与接触面积，使「同一闭合量」下法向力分布更均匀——视触觉可观测到压力重心偏移，作为**滑移前兆**。

### 与 VTLA 任务

- **pick-place**：力闭合不足 → 抬起时滑移；触觉滑移检测触发重抓或增力。
- **in-hand 操作**：多指力重分配；需理解摩擦锥而非仅关节位置。
- **策略学习**：奖励若只盯位姿，忽略 \(\sum F_i\) 平衡，真机易**假成功**（夹住但未真正承载）。

力闭合分析多假设**点接触 + 库仑**；精细仿真或软指需结合第二节软接触与第三节 LuGre（09 篇）。

## 六、从接触力到关节 \(\tau_{ext}=J^\top F\)

[04 篇](./04_dynamics_equation_properties.md) 与 [06 篇](./06_task_space_dynamics.md) 已给出映射骨架；本篇在**多接触**场景下补全用法。

### 单点接触

设接触点空间力（wrench 或纯力）为 \(F \in \mathbb{R}^3\) 或 \(\mathbb{R}^6\)，对应雅可比 \(J_c(q) \in \mathbb{R}^{m \times n}\)（与 [01 运动学回顾](./01_kinematics_review.md) 中末端 \(J\) 同源，但取**接触点**而非 TCP）：

\[
\tau_{ext} = J_c^\top(q)\, F
\]

**虚功原理**：\(\delta q^\top \tau_{ext} = \delta x_c^\top F\)，与 \(\dot x_c = J_c \dot q\) 对偶。控制律 \(\tau\) 与 \(\tau_{ext}\) 在关节空间**相加**（同一方程右端）。

### 多指 / 多接触叠加

\[
\tau_{ext} = \sum_{i=1}^{N_c} J_{c,i}^\top(q)\, F_i
\]

每指、每环境接触点各一组 \((J_{c,i}, F_i)\)。抓取时 \(F_i\) 含法向夹持力与摩擦切向力；桌面支撑时环境接触 \(F_i\) 可能固定于世界坐标系。

```
指尖 i：F_i = f_n,i n_i + f_t,i  →  J_{c,i}^T F_i
                    ↓
              τ_ext = Σ_i J_{c,i}^T F_i
                    ↓
        M q̈ + C q̇ + G = τ + τ_ext
```

### 与任务空间控制的关系

[07 篇](./07_dynamics_based_control.md) 操作空间律 \(\tau = J^\top F_{cmd} + \cdots\) 中，\(F_{cmd}\) 为**电机主动施加**的末端力；环境反作用 \(F_{ext}\) 经同一 \(J\)（或 \(J_c\)）产生 **\(\tau_{ext}\)**。闭环中测得或触觉估计的往往是 **\(F_{ext}\)**，而非直接的 \(\tau_{ext}\)：

| 量 | 含义 |
|----|------|
| \(\tau\) | 电机指令广义力 |
| \(J^\top F_{cmd}\) | 控制律产生的任务空间力映回关节 |
| \(\tau_{ext} = \sum J_{c,i}^\top F_i\) | 环境接触的反作用力 |
| 关节力矩传感 / 电流估计 | 常混合 \(\tau\) 与 \(\tau_{ext}\) 的效果 |

**触觉 → \(\tau_{ext}\)**：各触觉单元反推局部 \(f_n, f_t\) → 聚合为各接触点 \(F_i\) → 上式求和。标定误差与接触点位置误差会直接污染 \(\tau_{ext}\)，进而影响导纳外环与力估计（09 篇）。

### 与 \(\Lambda(x)\) 的衔接

接触存在时，任务空间方程（[06 篇](./06_task_space_dynamics.md)）：

\[
\Lambda(x)\,\ddot x + \mu + p = F_{cmd} + F_{ext}
\]

\(F_{ext}\) 即环境接触在末端等效 wrench；与关节空间 \(\tau_{ext}\) 通过 \(J\) 联系。阻抗设定 \(K,D\) 时，**实际** \(\ddot x\) 由 \(F_{ext}\) 与柔顺共同决定——\(F_{ext}\) 的模型即本篇第二节–第四节。

## 小结

- **接触动力学**解释 \(\tau_{ext}\) 的来源；VTLA/视触觉需把触觉观测对齐到 **\(F\) 与 \(\tau_{ext}=J^\top F\)**，并与 07 的阻抗/混合设定一致。
- **点接触**便于力闭合与硬约束分析；**软接触**改善数值稳定与柔顺 Sim2Real，更贴近弹性触觉传感器。
- **库仑摩擦**简单、与摩擦锥/互补配套，适于抓取分析与多数仿真；**LuGre** 刻画粘滑与预滑动，适于精细滑移与力控验证。
- **互补性**：\(f_n\) 与 \(\phi\)（或 \(v_n\)）互补，摩擦在锥内或滑移边界；MuJoCo/Drake/Pinocchio 背后多为 LCP/NCP 或软约束近似（实现见 09）。
- **力闭合**保证摩擦锥内可平衡任意（有界）外力；抓取稳定性需平衡 + 摩擦可行 + 抗扰。
- **多接触** \(\tau_{ext} = \sum_i J_{c,i}^\top F_i\) 是标准方程与触觉估力的汇聚点。
