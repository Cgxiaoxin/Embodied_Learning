## 一、工具定位：MuJoCo / Pinocchio / Drake / RBDL

刚体动力学与接触仿真在开源生态中分工明确：**有的负责「世界怎么动」**，**有的负责「给定运动算力矩」**，**有的把两者与优化/控制绑在一起**。下表是 L1 层面的选型地图（非 exhaustive，侧重与 [01–08 篇](./00_index.md) 的衔接）。

| 工具 | 核心能力 | 接触 / 摩擦 | 典型栈 | 与本系列关系 |
|------|----------|-------------|--------|--------------|
| **MuJoCo** | 快速刚体仿真、约束求解、RL 环境 | 软约束 + 迭代 LCP 族；`condim` 控制摩擦维；`solref`/`solimp` 调柔顺 | OpenAI Gym / Brax / robosuite / LIBERO | [08 篇](./08_contact_dynamics.md) 互补约束的默认实现；VLA 仿真 benchmark（如 LIBERO）常用 |
| **Pinocchio** | \(O(n)\) 动力学：RNEA、ABA、CRBA；解析雅可比；\(Y\theta\) 回归器 | **不内置**接触求解；接触力由外部仿真器或 QP 注入 \(\tau_{ext}\) | 与 MuJoCo / ROS2 / Crocoddyl / 自研 WBC 耦合 | [02 NE](./02_newton_euler.md)、[05 辨识](./05_parameter_identification.md) 的工程载体 |
| **Drake** | 多体 + 符号/自动微分 + 优化 + 接触互补约束 | `ComplementarityConstraint`、软接触、明确摩擦锥建模 | 轨迹优化、MPC、系统辨识、教学 | [03 拉格朗日](./03_lagrangian.md) 与接触互补的「可证明」侧 |
| **RBDL** | 轻量 NE 动力学（C++），API 简洁 | 无接触；常作纯动力学核 | 嵌入式、教学、与自研控制器 | 与 Pinocchio 定位相近，生态更小 |

### 分工直觉

```
URDF / MJCF 模型
      ↓
┌─────────────────┬──────────────────┐
│ 仿真「世界」     │  动力学「算式」    │
│ MuJoCo / Drake  │  Pinocchio / RBDL │
│ 接触、摩擦、积分  │  M,C,G, J, τ, Yθ  │
└────────┬────────┴────────┬─────────┘
         │                 │
         └──── WBC-QP / MPC / RL 策略 ────┘
```

**常见组合**：

- **RL / VLA 仿真**：MuJoCo（环境）+ 策略网络；动力学隐式在仿真器内，策略不直接调 \(M,C,G\)。
- **力控 / WBC 部署**：Pinocchio（RNEA 前馈 + 雅可比）+ 上层 QP + 真机电流环；接触力来自 F/T 传感或触觉估计。
- **轨迹优化 / 可微规划**：Drake 或 MuJoCo MJX + 自动微分；接触有时软化为惩罚便于求梯度。

**选型口诀**：要**大规模接触 RL** → MuJoCo；要**实时 \(\tau_{ff}\) 与辨识** → Pinocchio/RBDL；要**互补约束 + 符号推导 + 优化一体** → Drake。四者不互斥，同一项目可「MuJoCo 训策略 + Pinocchio 真机前馈」。

## 二、Sim2Real：动力学参数域随机化

**Sim2Real（simulation-to-reality）** 指在仿真中训练或验证的策略/控制器迁移到真机。动力学层的主要鸿沟来自：**模型参数不准**、**接触与摩擦抽象过粗**、**驱动与传感延迟**（[08 篇](./08_contact_dynamics.md) 已述点接触 vs 软接触、库仑 vs LuGre）。

### 域随机化（Domain Randomization, DR）

在仿真**每回合或每步**对物理/观测参数采样，扩大训练分布，使真机落在包络内：

| 随机化对象 | 典型范围 / 方式 | 对应系列概念 |
|------------|-----------------|--------------|
| 连杆质量、惯量、质心 | \(\pm 10\% \sim 50\%\) 或对数均匀 | [05 辨识](./05_parameter_identification.md) 的 \(\theta\) 不确定度 |
| 摩擦系数 \(\mu, \mu_d\) | 均匀 / 对数均匀 | [08 篇](./08_contact_dynamics.md) 库仑参数 |
| 接触刚度 \(k_n, d_n\) | 软接触、`solimp` 缩放 | 08 软接触、触觉传感器等效柔顺 |
| 电机增益、阻尼、延迟 | 一阶滞后 + 噪声 | [07 阻抗](./07_dynamics_based_control.md) 手感与带宽 |
| 外力扰动、传感噪声 | 关节力矩 / 末端扰动 | \(\tau_{ext}\) 未建模部分 |
| 视觉 / 触觉外观 | 纹理、光照、传感器噪声 | VLA 观测侧（见 [01-VLA](../01-VLA算法入门.md)） |

**动力学 DR 原则**：

1. **先随机化「结构已知、数值未知」的量**——质量、摩擦、接触刚度；比盲目加大噪声更有效。
2. **与任务相关**：抓取重 \(\mu\) 与接触刚度；行走重足端摩擦与躯干惯量。
3. **与辨识互补**：有 [05 篇](./05_parameter_identification.md) 激励轨迹辨识结果时，以辨识均值为中心、协方差为采样宽度，优于纯瞎猜。
4. **接触 DR 优先于无限刚性**：在 MuJoCo 中适度软化接触并随机 `solref`，往往比只随机质量更能缓解「仿真一顶就停、真机顶穿或弹跳」。

```
仿真训练分布  ──DR 扩大──►  应覆盖真机参数点
                              ↑
                         辨识 / 手册标定
```

**局限**：DR 不能替代错误接触模型（如无摩擦的推箱子）；极端接触任务常需 **系统辨识 + 少量真机微调（RL / BC）**（[02-VLA与RL进阶](../02-VLA与RL进阶.md) 中的后训练范式）。

## 三、基于模型的 RL / 可微物理 / 结构先验（\(M,C,G\) 嵌入）

纯模型无关 RL 把动力学当黑盒；**基于模型的 RL（MBRL）** 与 **可微物理** 则显式或隐式使用 \(M(q), C(q,\dot q), G(q)\)（[04 篇](./04_dynamics_equation_properties.md)）。

### 基于模型的 RL（MBRL）

用学习或解析的动力学模型 \(\hat f(q,\dot q,\tau)\) 做：

- **短视界 rollout** 估回报、做 MPC；
- **数据增广**：在模型里生成虚拟轨迹；
- **梯度传播**：若 \(\hat f\) 可微，对策略或目标求 \(\partial \mathcal{L}/\partial \pi\)。

机器人上 \(\hat f\) 常分解为 **\(M,C,G\) 结构 + 残差网络**（残差吸收摩擦、柔性、齿轮间隙），比纯神经网络更省数据、外推更稳。

### 可微物理（Differentiable Physics）

**目标**：损失 \(\mathcal{L}\) 对设计变量（轨迹、参数、策略权重）可反传。

| 路径 | 做法 | 工具示例 |
|------|------|----------|
| 软接触可微 | 惩罚穿透、平滑摩擦 | Brax、MuJoCo MJX、DiffTaichi |
| 解析动力学可微 | \(M,C,G\) 用 AD 链式求导 | Drake、Jax 版 Pinocchio、Dojo |
| 隐式层 | 仿真一步 = 隐函数，反传解 KKT | 接触互补的平滑近似 |

**与 08 的 tension**：硬互补（LCP）不可微；训练时常用**软接触**换梯度，部署或验证时用硬接触 / 真机。Sim2Real 要在两者间做 **curriculum** 或 DR。

### 结构先验：\(M,C,G\) 嵌入

**结构先验（structural prior）** 指网络或优化变量不任意参数化 \(\ddot q\)，而约束在：

\[
M(q)\,\ddot q + C(q,\dot q)\,\dot q + G(q) = \tau + \tau_{ext}
\]

**嵌入方式**：

1. **物理前馈 + 学习残差**：\(\tau = \hat M \ddot q_d + \hat C \dot q + \hat G + \pi_\theta(q,\dot q)\)（连接 [07 CTC](./07_dynamics_based_control.md)）。
2. **拉格朗日神经网络 / Hamiltonian NN**：学习 \(T,V\) 或 \(M,G\) 的低维参数化，保证 \(M\) 对称正定。
3. **操作空间**：在 \(\Lambda(x)\) 层嵌入（[06 篇](./06_task_space_dynamics.md)），适合任务空间策略输出 \(\Delta x\)。

**为何对 VLA 重要**：VLA 输出多为 **末端增量 / 关节目标**，不是力矩。中间层用 \(J,\Lambda\) 或阻抗把动作映射到 \(\tau\) 时，**显式 \(M,C,G\)** 可减少「看起来合理但力矩不可行」的动作，并与 WBC 安全约束一致（下节）。

```
VLA 动作 Δx / q_d
      ↓  J, Λ, 阻抗（06–07）
  τ = M q̈_d + C q̇ + G + …
      ↓  仿真 / 真机
  τ_ext（08）← 接触
```

## 四、WBC：动力学约束进 QP

**全身控制（Whole-Body Control, WBC）** 在冗余机器人（人形、双臂、移动操作）上，把**任务、接触、关节限位**统一写成 **二次规划（QP）**，动力学方程作为**等式或软约束**进入。

### 标准形式（概念）

决策变量常取 \(\ddot q\)（或 \(\tau\)、接触力 \(F_c\)）。典型目标：

\[
\min_{\ddot q,\,F_c,\,\tau} \ \|\ddot q - \ddot q_{des}\|_{W_q}^2 + \|F_c - F_{c,des}\|_{W_f}^2 + \|\tau\|_{W_\tau}^2
\]

**动力学等式**（浮动基或固定基）：

\[
M(q)\,\ddot q + C(q,\dot q)\,\dot q + G(q) = \tau + J_c^\top(q)\, F_c
\]

**接触约束**（[08 篇](./08_contact_dynamics.md)）：\(F_c\) 在摩擦锥内；非穿透 \(\ddot\phi \ge 0\)（或速度级约束）。多接触时 \(F_c = [F_1^\top,\ldots]^\top\)，\(\tau_{ext} = J_c^\top F_c\)。

**不等式**：关节力矩/速度/加速度限位、自碰撞、质心 ZMP（若适用）。

```
任务空间目标（末端、姿态、质心）
        ↓  堆成 q̈_des, F_c,des
   QP：min 跟踪误差 + 正则
   s.t.  M q̈ + C q̇ + G = τ + J_c^T F_c
        F_c ∈ 摩擦锥, 限位
        ↓
   τ → 电机；Pinocchio RNEA 可作 τ_ff 或验证
```

### 与 07、08 的关系

| 模块 | 角色 |
|------|------|
| [07 阻抗/混合](./07_dynamics_based_control.md) | 单臂或低维任务；WBC 是其**多任务、多接触**推广 |
| [08 接触](./08_contact_dynamics.md) | 摩擦锥与 \(\tau_{ext}\) 是 QP 约束来源 |
| Pinocchio / RBDL | 每周期更新 \(M,C,G,J_c\) |
| Drake / 自研栈 | 接触互补可硬编码进 QP 或松弛 |

**VTLA 接口**：上层 VLA 或行为树给出 **\(x_d\)、抓取语义、柔顺 \(K,D\)**；WBC 将其转为满足动力学的 \(\tau\)，并在接触变化时分配多指力。**触觉估计的 \(F_c\)** 可作为等式右端或软测量进 QP（第五节）。

## 五、触觉信号反推接触力（VTLA 桥接）

[08 篇](./08_contact_dynamics.md) 给出 \(\tau_{ext} = \sum_i J_{c,i}^\top F_i\)。**视触觉 / VTLA** 管线中，策略输入是图像与触觉 RGB/压力图，动力学层需要 **\(\hat F_i\)** 或等效 \(\hat\tau_{ext}\)。本节是动力学系列对 VTLA 的**显式桥接**。

### 观测 → 力的层次

| 传感器 | 原始观测 | 反推目标 | 常用方法 |
|--------|----------|----------|----------|
| GelSight / DIGIT | 触觉 RGB、形变场 | 法向压力分布 → \(f_n\)，剪切 → \(f_t\) | 光度立体、CNN 回归、有限元标定 |
| 电阻 / 电容阵列 | 压力网格 | 接触中心、总法向力 | 双线性插值 + 标定曲线 |
| 六维力矩（腕部） | \(F_{FT}\) | 单点等效 \(F\) | 直接测量（非触觉，但常融合） |
| 关节力矩 / 电流 | \(\tau_{meas}\) | 分离 \(\tau_{cmd}\) 得 \(\hat\tau_{ext}\) | 动量观测器、残差滤波 |

### 从触觉到 \(\tau_{ext}\) 的管线

```
触觉图像 / 压力图
      ↓  标定网络或查表
  局部 f_n, f_t（各 taxel 或 patch）
      ↓  接触点位置 p_i、法向 n_i（运动学 + 视觉）
  接触点力 F_i = f_n,i n_i + f_t,i
      ↓  J_{c,i}(q)
  τ_ext = Σ_i J_{c,i}^T F_i
      ↓
  导纳外环 / WBC 测量 / 日志与 RL 奖励
```

**与 07 导纳**：导纳律 \(\ddot x = M_a^{-1}(F_{meas} - D\dot x - K\Delta x)\) 中 \(F_{meas}\) 常来自 **触觉反推** 而非腕力传感器。**阻抗**外环若只有位置内环，触觉力用于 **触地检测、滑移事件、力限制**。

### 误差来源与 Sim2Real

| 误差 | 后果 | 缓解 |
|------|------|------|
| 接触点位置 \(p_i\) 偏 | \(J_{c,i}\) 错 → \(\tau_{ext}\) 方向错 | 视觉定位 + 指尖运动学联合标定 |
| 摩擦 / 剪切标定 | \(f_t\) 低估 → 滑移检测迟 | 08 库仑/LuGre 参数 DR；真机滑移数据微调 |
| 软传感器迟滞 | 力峰值与相位差 | 动态补偿、LuGre 类模型 |
| 仿真无分布触觉 | 策略过拟合视觉 | 仿真中加合成压力图或 DR 形变场 |

**与学习的衔接**：RL 奖励可用 \(\|\hat F_n - F_{target}\|\)、滑移惩罚；VLA **不必须**输出力，但 **力估计模块** 可为安全监控与后训练提供信号（见 [02-VLA与RL进阶](../02-VLA与RL进阶.md) 奖励塑形）。

### 融合策略

实践中常 **多源融合**：触觉给 **局部法向与滑移**；腕 F/T 给 **全局 wrench**；动量观测器给 **关节级 \(\hat\tau_{ext}\)**。卡尔曼滤波或小型学习融合网络，在接触点已知时以触觉为主、其余时刻以 F/T 为主。

## 小结

- **MuJoCo** 擅长大规模接触仿真与 RL；**Pinocchio/RBDL** 擅长时间动力学与辨识；**Drake** 擅长互补接触与可微优化——常组合使用而非单选。
- **域随机化** 应覆盖质量、摩擦、接触刚度与驱动动态；与 [05 辨识](./05_parameter_identification.md) 和 [08 接触模型](./08_contact_dynamics.md) 对齐，缓解 Sim2Real。
- **MBRL / 可微物理** 利用 \(M,C,G\) 结构或软接触梯度；训练与部署的接触模型可 deliberately 不一致，需 DR 或课程学习。
- **WBC-QP** 把 \(M\ddot q+C\dot q+G=\tau+J_c^\top F_c\) 与摩擦锥、任务跟踪统一求解，是 VLA 输出与多接触力控的常用底层。
- **触觉 → \(\hat F\) → \(\tau_{ext}\)** 是 VTLA 与动力学方程的汇聚点；标定与接触点误差是 Sim2Real 关键。
