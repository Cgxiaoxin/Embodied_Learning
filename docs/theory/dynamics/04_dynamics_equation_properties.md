# 动力学方程性质：\(M,C,G\) 与 \(\tau_{ext}\)

> **类型**：理论 · **层级**：L1 · **状态**：草稿 · **更新**：2026-09-11  
> **关联**：[03 拉格朗日](./03_lagrangian.md) · [动力学索引](./00_index.md) · [05 参数辨识](./05_parameter_identification.md)

> 拉格朗日推导给出关节空间标准形式 \(M(q)\ddot q+C(q,\dot q)\dot q+G(q)=\tau+\tau_{ext}\)。本篇不重复推导，而聚焦**各项的物理含义与矩阵性质**：\(M\) 的对称正定性、\(C\) 的科氏/离心作用与 \(\dot M-2C\) 反对称性、\(G\) 的重力补偿、惯性参数的 \(Y\theta\) 线性化，以及外力 \(\tau_{ext}\) 在接触与视触觉中的角色。这些性质是计算力矩、自适应控制、阻抗设计与参数辨识的共同语言。

## 一、标准形式回顾

由 [03 拉格朗日](./03_lagrangian.md) 的欧拉-拉格朗日整理，固定基座、树形拓扑机械臂的**标准关节空间动力学方程**为：

\[
M(q)\,\ddot q + C(q,\dot q)\,\dot q + G(q) = \tau + \tau_{ext}
\]

| 符号 | 维度 | 含义 |
|------|------|------|
| \(q,\dot q,\ddot q\) | \(n\times 1\) | 关节位置、速度、加速度 |
| \(M(q)\) | \(n\times n\) | 广义惯性矩阵（质量矩阵） |
| \(C(q,\dot q)\) | \(n\times n\) | 科氏/离心矩阵；\(C\dot q\) 为速度相关广义力 |
| \(G(q)\) | \(n\times 1\) | 重力广义力 |
| \(\tau\) | \(n\times 1\) | 关节驱动力矩（控制输入） |
| \(\tau_{ext}\) | \(n\times 1\) | 外力/接触力等效到关节的广义力 |

**左端**是「产生运动所需的广义力」：惯性 + 速度耦合 + 重力。**右端**是施加在关节上的力矩：电机输出 \(\tau\) 与环境/接触带来的 \(\tau_{ext}\)。无接触、无外力时 \(\tau_{ext}=0\)；抓取、推挤、碰撞时 \(\tau_{ext}\neq 0\)，且往往正是控制与感知的核心对象。

与牛顿-欧拉（[02 篇](./02_newton_euler.md)）的关系：同一物理系统，NE 直接递推得到 \(\tau\)；拉格朗日路径把 \(\tau\) 拆成 \(M\ddot q+C\dot q+G\) 的结构。Pinocchio 的 `rnea` 算的是右端已知 \(\ddot q\) 时的总需求力矩；`crba` 组装 \(M\)。数值上两者应一致。

## 二、\(M(q)\)：对称正定与物理含义

### 对称性

动能 \(T=\frac{1}{2}\dot q^\top M(q)\dot q\)。对任意 \(\dot q\)，\(T\) 为标量，故 \(M\) **对称**：

\[
M_{ij}(q) = M_{ji}(q)
\]

### 正定性

对树形机械臂（无冗余约束、无奇异位形），对任意非零 \(\dot q\)，动能 \(T>0\)，故 \(M(q)\) **正定**（工程上常称对称正定，SPD）：

\[
\dot q^\top M(q)\,\dot q > 0,\quad \forall\,\dot q\neq 0
\]

**物理含义**：\(M(q)\) 刻画「在当前位形 \(q\) 下，各关节加速度对广义惯性力的耦合」。对角元 \(M_{ii}\) 反映关节 \(i\) 的「等效惯量」；非对角元 \(M_{ij}\) 反映关节 \(i\) 加速时，关节 \(j\) 感受到的惯性耦合。

**位形依赖**：\(M\) 随 \(q\) 变化——手臂伸直与蜷缩时，同一关节加速度所需的力矩不同。任务空间操作惯量 \(\Lambda=(JM^{-1}J^\top)^{-1}\)（见 [06 任务空间动力学](./06_task_space_dynamics.md)）正是把关节空间 \(M\) 映到末端笛卡尔空间。

### 工程注意

- **奇异位形**：\(J\) 降秩时任务空间惯量发散；关节空间 \(M\) 本身仍通常满秩，但某些冗余/闭链构型可能使 \(M\) 奇异或近奇异。
- **模型误差**：URDF 中质量、质心、惯量错误会直接体现在 \(M\) 上，影响前馈补偿与阻抗参数整定。
- **计算**：显式求 \(M^{-1}\) 为 \(O(n^3)\)；实时控制多用 RNEA 避免求逆，或 Cholesky 分解 \(M\) 做正向动力学。

## 三、\(C(q,\dot q)\)：科氏/离心与 \(\dot M-2C\) 反对称性

### 科氏与离心

\(C(q,\dot q)\dot q\) 吸收动能 \(T(q,\dot q)\) 中对 \(q\) 的依赖所产生的**速度二次项**——在笛卡尔空间对应科氏加速度 \(\omega\times v\) 与离心项 \(\omega\times(\omega\times r)\) 在广义坐标下的投影。直观上：

- **离心**：单关节匀速转动时，连杆仍产生「往外甩」的惯性效应；
- **科氏**：多关节同时运动时，一个关节的速度会改变另一关节加速所需的力矩。

\(C\) 的选取**不唯一**：任意满足 \(C\dot q = (\text{速度二次项})\) 的矩阵都可用。但不同选取会影响后续性质证明的便利性。

### Christoffel 形式

常用定义（与 03 篇一致）：

\[
c_{jk\ell} = \frac{1}{2}\Big(
\frac{\partial m_{j\ell}}{\partial q_k}
+ \frac{\partial m_{k\ell}}{\partial q_j}
- \frac{\partial m_{jk}}{\partial q_\ell}
\Big),\qquad
\big(C(q,\dot q)\dot q\big)_j = \sum_{k,\ell} c_{jk\ell}\,\dot q_k \dot q_\ell
\]

该形式保证 **功率无贡献**：

\[
\dot q^\top C(q,\dot q)\,\dot q = 0
\]

即科氏/离心力不做净功——纯惯性效应，可由动能变化解释。

### \(\dot M - 2C\) 反对称性

对 Christoffel 型 \(C\)，有核心性质：

\[
N(q,\dot q) \triangleq \dot M(q,\dot q) - 2\,C(q,\dot q) \quad \text{为反对称矩阵}
\]

即 \(N^\top = -N\)，等价于对任意 \(x,y\in\mathbb{R}^n\)：

\[
x^\top N\, y = -\,y^\top N\, x
\]

取 \(x=y=\dot q\) 得 \(\dot q^\top N\dot q=0\)，与上式一致。

**证明思路（压缩）**：由 \(M\dot q = \partial T/\partial\dot q\) 对时间求导，用 \(\partial M/\partial q_k\) 的 Christoffel 组合可整理出 \(\dot M - 2C\) 的 \((j,k)\) 元为 \(\frac{1}{2}\sum_\ell(\partial m_{j\ell}/\partial q_k - \partial m_{k\ell}/\partial q_j)\dot q_\ell\)，交换 \(j,k\) 后变号。

### 控制中的用途

反对称性在**稳定性证明**与**自适应控制**中至关重要。考虑闭环 \(\tau = \tau_{ctrl}\)，左乘 \(\dot q^\top\)：

\[
\dot q^\top M\ddot q + \dot q^\top C\dot q + \dot q^\top G = \dot q^\top\tau + \dot q^\top\tau_{ext}
\]

利用 \(\frac{d}{dt}(\frac{1}{2}\dot q^\top M\dot q) = \dot q^\top M\ddot q + \frac{1}{2}\dot q^\top\dot M\dot q\) 与 \(\dot q^\top C\dot q=0\)，可得**动能变化率**：

\[
\frac{d}{dt}T = \dot q^\top\tau + \dot q^\top\tau_{ext} - \dot q^\top G
\]

其中 \(\dot q^\top\dot M\dot q\) 项通过 \(\dot M - 2C\) 反对称性在能量平衡中**自动消去**不当的「虚假耗散/源项」。典型应用：

| 应用 | 如何利用反对称性 |
|------|------------------|
| **计算力矩 + PD** | 证明在 \(\tau_{ext}=0\)、重力补偿正确时，跟踪误差能量单调下降 |
| **自适应控制** | 参数估计律 \(\dot{\hat\theta} = \Gamma Y^\top\dot q\) 与 \(Y\theta\) 结构配合，避免 \(\dot M\) 项破坏被动性 |
| **阻抗/操作空间** | 任务空间能量整形时，保证科氏项不引入非物理能量注入 |

若 \(C\) 未按 Christoffel 选取，\(\dot M-2C\) 可能不再反对称，稳定性证明需额外修正项——这也是控制器推导时「固定一种 \(C\) 定义」的原因。

## 四、\(G(q)\)：重力补偿

\(G(q)\) 来自势能梯度：

\[
G(q) = \frac{\partial V}{\partial q}
\]

对固定基座机械臂，\(V = \sum_i m_i\, g^\top r_{c,i}(q)\)（质心高度与重力方向），故 \(G\) 仅依赖位形 \(q\)，与速度无关。

**工程含义**：

- **重力补偿（gravity compensation）**：令 \(\tau_{ff} = G(q)\) 或 \(\tau_{ff} = G(\hat q)\)，可大幅减轻反馈环负担，使 PD 只需处理惯性/科氏与跟踪误差。
- **离线标定**：\(G\) 对质量、质心参数线性（见下节 \(Y\theta\)），可单独辨识重力项用于前馈。
- **竖直/水平构型**：\(G\) 在手臂水平伸展时往往最大，竖直下垂时可能接近零——整定阻抗与力控增益时需考虑位形依赖。

无外力时，若 \(\tau = G(q) + \tau_{ctrl}\) 且 \(\tau_{ctrl}\) 为 PD，平衡点处 \(\dot q=0\) 时方程简化为 \(M\ddot q + \tau_{ctrl} = 0\)（在重力已补偿前提下），便于分析定点稳定性。

## 五、参数线性化：\(Y(q,\dot q,\ddot q)\theta\)

刚体惯性参数（各连杆质量 \(m_i\)、质心位置、惯量张量元素）在 \(M,C,G\) 中**线性出现**。可合并为参数向量 \(\theta\in\mathbb{R}^p\)（\(p\) 为独立惯性参数个数，常小于「每连杆 10 个」的朴素计数，因存在冗余），使得：

\[
Y(q,\dot q,\ddot q)\,\theta = M(q)\ddot q + C(q,\dot q)\dot q + G(q)
\]

其中 \(Y\in\mathbb{R}^{n\times p}\) 称为**回归矩阵（regressor）**。上式右端即无外力时的逆动力学 \(\tau\)。

**直观**：对固定 \((q,\dot q,\ddot q)\)，\(Y\) 的每一列是「若 \(\theta_j=1\)、其余为 0，产生的关节力矩向量」。因此

\[
\tau = Y(q,\dot q,\ddot q)\,\theta + \tau_{ext}
\]

（当 \(\tau_{ext}\) 已知或可忽略时）是**参数辨识**的标准起点。

### 基参数与可辨识性（预告）

并非所有 \(p\) 个参数都独立可辨识：

- **基参数（base parameters）**：最小参数集，使 \(Y\theta\) 能表示任意可行动力学；冗余参数在任意轨迹上不可区分。
- **持续激励**：辨识需要轨迹使 \(Y\) 列满秩或条件数良好；静止或重复小范围运动往往不够。
- **建模残差与噪声**：实际辨识将测量写为 \(\tau = Y\theta + \epsilon\)，\(\epsilon\) 含传感器噪声、未建模效应及 \(\tau_{ext}\) 等残差；常用最小二乘或递推最小二乘估计 \(\hat\theta\)。

详细流程——激励轨迹设计、SVD 求基参数、最小二乘与正则化——见 [05 参数辨识](./05_parameter_identification.md)。本篇只需记住：**拉格朗日结构使 \(\tau\) 对 \(\theta\) 线性**，这是离线/在线辨识与自适应控制能「分离参数与状态」的代数基础。

### 与 NE 的对比

NE 递推对 \(\theta\) 是**隐式**的：改一个质量会改变整条递推链。拉格朗日或符号工具便于**显式生成 \(Y\)**；工程上 Pinocchio 等也提供 `computeJointTorqueRegressor` 一类接口。实时控制仍多用 RNEA；辨识与自适应多用 \(Y\theta\)。

## 六、\(\tau_{ext}\)：接触、外力与触觉接口

### 定义与映射

\(\tau_{ext}\) 汇总**环境施加在机器人上的外力/外力矩**在关节空间的等效：

\[
\tau_{ext} = \sum_k J_k^\top(q)\, F_k
\]

其中 \(F_k\) 为作用在连杆 \(k\) 上的空间力（线力 + 力矩，6 维或 3 维点力），\(J_k\) 为相应作用点的雅可比（见 [01 运动学回顾](./01_kinematics_review.md)）。常见情形：

| 情形 | \(F_k\) 来源 | \(\tau_{ext}\) 特点 |
|------|--------------|---------------------|
| 末端接触 | 法向/切向接触力 | 主要通过末端 \(J^\top\) 进入 |
| 多指抓取 | 各指尖接触力 | 多组 \(J_i^\top F_i\) 叠加 |
| 碰撞 | 瞬时大 \(F\) | 高频、需仿真或柔顺处理 |
| 人为拖拽 | 手施力 | 用于示教、导纳控制 |

方程 \(M\ddot q+C\dot q+G=\tau+\tau_{ext}\) 表明：**接触不改变 \(M,C,G\) 的结构**，而是作为右端广义力与电机力矩 \(\tau\) 并列——控制律设计时，若把 \(\tau_{ext}\) 当扰动，需阻抗/力控或估计补偿；若任务就是要产生特定接触力，则 \(\tau_{ext}\) 是目标而非噪声。

### 与触觉、VTLA 的衔接（短）

视触觉（VTLA）与力控部署中，**触觉传感器测量的是接触界面的局部信息**（压力分布、剪切、滑移），而动力学方程中的 \(\tau_{ext}\) 是**关节空间聚合后的广义力**。二者通过接触模型与雅可比联系：触觉 → 估计或约束 \(F\) → \(J^\top F = \tau_{ext}\)。策略或 WBC 输出 \(\tau\) 时，若忽略 \(\tau_{ext}\)，抓取、插拔、折纸等任务会出现「看起来到位了但力不对」的 Sim2Real 落差。因此：

- **力控/阻抗**（07 篇）在设计上预留 \(\tau_{ext}\) 或期望接触力的通道；
- **接触动力学**（08 篇）给出 \(F\) 与约束的关系；
- **仿真与触觉估力**（09 篇）讨论从触觉反推 \(F\) 与 \(\tau_{ext}\)。

本篇不展开 VTLA 管线；读者只需建立对应：**触觉观测 ↔ 接触力 \(F\) ↔ \(\tau_{ext}\) ↔ 标准方程右端**。

## 小结

- 标准形式 \(M\ddot q+C\dot q+G=\tau+\tau_{ext}\) 是力控、辨识与接触分析的共同起点；与 NE 物理等价，结构更利于证明与线性参数化。
- \(M(q)\) 对称正定，刻画位形相关的广义惯性；\(G(q)=\partial V/\partial q\) 可重力前馈补偿。
- \(C\) 表示科氏/离心；Christoffel 选取使 \(\dot q^\top C\dot q=0\) 且 \(\dot M-2C\) **反对称**，支撑能量平衡与自适应稳定性分析。
- 惯性参数满足 \(Y(q,\dot q,\ddot q)\theta = M\ddot q+C\dot q+G\)；基参数与辨识方法见下一篇。
- \(\tau_{ext}=J^\top F\) 将接触/外力映入方程；触觉与 VTLA 需把传感信息与 \(\tau_{ext}\) 对齐。
