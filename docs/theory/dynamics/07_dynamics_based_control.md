## 一、基于模型控制总览

**基于模型控制（model-based control）** 指在控制律中**显式使用**动力学模型 \(M,C,G\)（及任务空间映射 \(J,\Lambda\)），而非纯 PID 黑盒。动机：

| 问题 | 纯关节 PID 的局限 | 模型前馈/结构控制的优势 |
|------|-------------------|-------------------------|
| 重力 | 各姿态需不同积分项 | \(G(q)\) 前馈，跟踪误差小 |
| 高速运动 | \(C\dot q\) 耦合被当扰动 | 科氏/离心补偿 |
| 力控 / 阻抗 | 刚度随位形漂移 | \(\Lambda(x)\) 或 \(M\) 补偿，手感一致 |
| 接触 | 刚性顶死 | 阻抗/混合设定柔顺子空间 |

标准关节方程（[04 篇](./04_dynamics_equation_properties.md)）：

\[
M(q)\,\ddot q + C(q,\dot q)\,\dot q + G(q) = \tau + \tau_{ext}
\]

**控制设计的三条主线**（本篇覆盖）：

1. **逆动力学 / 反馈线性化**：用 \(\tau\) 抵消 \(M,C,G\)，把闭环变成「名义双积分器 + PD」→ **计算力矩控制（CTC）**。
2. **任务空间力/位分解**：在 \(x\) 或 wrench 子空间划分「跟踪位置」与「跟踪力」→ **混合控制**；或设定虚拟弹簧阻尼 → **阻抗 / 导纳**。
3. **模型不确定**：\(\hat M,\hat C,\hat G\) 或 \(\hat\theta\) 有误差 → **自适应**（利用 \(Y\theta\) 结构）或 **鲁棒 / 滑模**（有界扰动假设）。

```
策略 / 示教 / WBC
        ↓  x_d, F_d, 阻抗 K,D
   任务空间律（混合 / 阻抗 / 操作空间）
        ↓  τ = f(M,C,G,J,Λ, …)
   关节执行 + 电流环
        ↓
   真机 ← τ_ext（接触，08 篇）
```

**前提**：URDF / 辨识得到的 \(\theta\)（[05 篇](./05_parameter_identification.md)）决定前馈质量；CTC 与操作空间阻抗对 \(\hat M,\hat\Lambda\) 误差敏感，但结构正确时仍远优于无模型 PD。

## 二、计算力矩控制（反馈线性化 + PD）

### 基本思想

若模型精确，选取

\[
\tau = M(q)\,v + C(q,\dot q)\,\dot q + G(q)
\]

代入 \(M\ddot q + C\dot q + G = \tau\)（暂设 \(\tau_{ext}=0\)），得

\[
\ddot q = v
\]

即非线性系统被**反馈线性化**为 \(n\) 个独立双积分器；\(v\) 为新的「虚拟输入」。取

\[
v = \ddot q_d + K_p\,(q_d - q) + K_d\,(\dot q_d - \dot q)
\]

闭环误差 \(e = q_d - q\) 满足 \( \ddot e + K_d \dot e + K_p e = \ddot q_d - \ddot q_d^{actual}\)（在 \(\ddot q_d\) 已知或可忽略时趋近 0）。这就是 **计算力矩控制（Computed Torque Control, CTC）**，也称 **逆动力学控制** 或 **反馈线性化控制**。

| 项 | 作用 |
|----|------|
| \(M(q)\,v\) | 按期望加速度 \(v\) 提供惯性力 |
| \(C\dot q\) | 抵消科氏/离心 |
| \(G(q)\) | 重力补偿 |
| \(K_p, K_d\) | 线性闭环，整定与二阶系统类似 |

### 任务空间 CTC（概念）

末端跟踪 \(x_d(t)\) 时，可先算 \(\ddot x_d\)，再通过 \(J\) 映回 \(\ddot q_d\)，或直接在操作空间（[06 篇](./06_task_space_dynamics.md)）写

\[
F = \Lambda(x)\,\ddot x_d + \mu(x,\dot x) + p(x) + \text{PD}(x_d - x)
\]

\[
\tau = J^\top F + \tau_0
\]

其中 \(\mu,p\) 为任务空间科氏/重力项，\(\tau_0\) 可为 null-space 关节项。核心仍是：**用 \(\Lambda,M,C,G\) 做前馈，用 PD 管误差**。

### 工程注意

| 问题 | 后果 | 常见处理 |
|------|------|----------|
| \(\hat M \neq M\) | 闭环仍含未抵消非线性 | 辨识 + 自适应；或鲁棒项 |
| \(\ddot q_d\) 噪声 | \(M\ddot q_d\) 抖动 | 轨迹滤波；加速度前馈限幅 |
| \(\tau_{ext}\neq 0\) | 接触时 \(e\) 无法为零 | 改阻抗/混合，见第三、四节 |
| 计算量 | 每周期 RNEA / CRBA | Pinocchio `rnea`；避免显式 \(M^{-1}\) |

CTC 是**非接触轨迹跟踪**的基准；一旦持续接触，\(\tau_{ext}\) 进入方程，纯位置 CTC 会在约束方向产生过大内力——需力/位混合或阻抗。

## 三、力/位混合控制（选择矩阵直觉）

**混合力/位控制（hybrid force/position control）** 在任务空间把 \(m\) 维 twist / wrench 拆成两个正交子空间：一部分**约束位置**（或速度），另一部分**约束力**（或 wrench 分量）。

### 选择矩阵

引入对角 **选择矩阵** \(S \in \mathbb{R}^{m\times m}\)（0/1 或 0~1 权重）：

\[
S = \mathrm{diag}(s_1,\ldots,s_m), \quad s_i \in [0,1]
\]

- **位控子空间**：\(S\) 中 \(s_i=1\) 的分量 → 跟踪 \(x_{d,i}\)（或 \(\dot x_{d,i}\)）；
- **力控子空间**：\(I-S\) 中 \(s_i=0\) 的分量 → 跟踪期望力 \(F_{d,i}\)（或保持零力）。

正交分解：

\[
S + (I-S) = I, \quad S(I-S) = 0
\]

**直觉**：在桌面擦拭任务中，垂直于桌面方向 \(s_i=0\)（力控，恒定法向力）；切平面内 \(s_i=1\)（位控，沿路径移动）。插孔时，孔轴方向力控、横向位控。

### 控制结构（概念）

位控子空间（示意）：

\[
F_x = \Lambda_x\,\ddot x_d + \cdots + K_p^x e_x + K_d^x \dot e_x
\]

力控子空间（示意）：

\[
F_f = F_d + K_f\,(F_d - F_{meas})
\]

合成 wrench \(F = S F_x + (I-S) F_f\)，再 \(\tau = J^\top F + G + \cdots\)。**关键**：\(S\) 必须在**合适的任务坐标系**中定义（如接触法向/切向），否则「力控方向」与物理接触不一致。

### 与约束的关系

理想混合控制假设：**位控方向无刚性约束、力控方向无运动**（或软约束）。真实接触中两子空间通过摩擦与 [08 篇](./08_contact_dynamics.md) 的互补约束耦合；\(S\) 选错会导致 fighting（位控方向顶死约束）或 drift（力控方向无人管）。

| 场景 | 典型 \(S\) 划分 |
|------|-----------------|
| 平面擦拭 | 法向力控，切向位控 |
| 插销入孔 | 轴向力控/柔顺，径向位控 |
| 双臂协同 | 每臂各自 \(S\)，或共同约束 |

混合控制是工业力控的经典框架；**阻抗**可看作「力/位子空间上用连续 \(K,D\) 代替硬切换 \(S\)」的柔顺化推广。

## 四、阻抗控制 vs 导纳控制

### 阻抗控制（impedance）

**目标**：使末端在接触方向表现像**质量-弹簧-阻尼**系统。期望关系（任务空间，示意）：

\[
F = \Lambda\,\ddot x_d + D\,(\dot x_d - \dot x) + K\,(x_d - x) + \text{（前馈）}
\]

或更常见的**目标阻抗**（环境力 \(F_{ext}\) 作用下）：

\[
F_{ext} \approx K\,\Delta x + D\,\Delta\dot x + M_d\,\Delta\ddot x
\]

\(K,D\)（及可选 \(M_d\)）为**虚拟弹簧、阻尼、惯量**——可调「软硬」。实现上由 **力矩层** 输出 \(\tau = J^\top F + \text{补偿}\)，机器人主动调节 \(F\) 以产生上述关系；需要较准确的 \(M,C,G\) 或 \(\Lambda\) 前馈，否则同样 \(K\) 在不同 \(q\) 下手感变。

**操作空间阻抗**（与 [06 篇](./06_task_space_dynamics.md) 衔接）：在 \(\Lambda\ddot x + \mu + p = F + F_{ext}\) 上令 \(F\) 含 \(K\Delta x + D\Delta\dot x\)，闭环在接触时自然「让步」，避免刚性碰撞。

### 导纳控制（admittance）

**目标**：同样的弹簧阻尼行为，但**外环在位置/速度**——测力（或估计 \(F_{ext}\)），根据

\[
M_d\,\ddot x_c + D\,(\dot x_c - \dot x) + K\,(x_c - x) = F_{ext}
\]

修正**指令轨迹** \(x_c\)，内环仍用位置/速度伺服跟踪 \(x_c\)。导纳 = **力输入 → 运动输出**，数学上是阻抗的逆（在 SISO 标量意义上 \(Z = F/\dot x\)，\(Y = 1/Z\)）。

| 对比 | 阻抗 | 导纳 |
|------|------|------|
| 外环输出 | 力 / 力矩 \(\tau\) | 修正后的 \(x_c, \dot x_c\) |
| 内环 | 常配合力矩前馈 | 位置/速度 PID（易用商业臂） |
| 传感器 | 力矩估计或关节力传感 | **末端力传感器**更常见 |
| 稳定性 | 低阻抗（软）时闭环惯量耦合 | 高刚度内环 + 外环柔化；注意延迟 |
| 典型硬件 | 力矩可控臂（如 Franka） | 带 F/T 的 position-controlled 臂 |

**何时选谁**：内环能直接控 \(\tau\) 且模型好 → 阻抗/操作空间力矩律；只有位置接口 + 六维力传感 → 导纳更现实。二者可组合（如导纳外环 + 阻抗力矩内环）。

### 与触觉 / VTLA 的衔接（短）

视触觉（VTLA）任务中，策略常输出**笛卡尔增量** \(\Delta x\) 或「沿某方向轻推」；真机接触时，**触觉**给出局部压力/滑移，而动力学层需要 **\(F_{ext}\) 或 \(\tau_{ext}\)** 与**柔顺设定**一致（[04 篇](./04_dynamics_equation_properties.md)）。阻抗/导纳提供统一接口：

- **策略 / VLA**：设 \(x_d\) 或 \(\Delta x\)；底层用 \(K,D\) 限制最大接触力，避免「到位了但捏碎/顶飞」；
- **触觉闭环**：触觉估计 \(\hat F\) 或滑移事件 → 调整 \(x_d\)（导纳式）或 \(F_d\)（阻抗式），等价于在 \(K,D\) 外再加一层**事件驱动**的柔顺；
- **Sim2Real**：仿真里忽略 \(\Lambda\) 与 \(\tau_{ext}\) 时，同样 \(K\) 在真机接触瞬间力峰值可差数倍——部署前应在多姿态标定 \(\hat M\)（[05 篇](./05_parameter_identification.md)）并在接触任务上扫 \(K,D\)。

对应链：**触觉观测 → \(\hat F\) → 导纳修正 \(x_c\) 或阻抗 \(F\)** → \(\tau = J^\top F\) → 环境 \(\tau_{ext}\)。[08 篇](./08_contact_dynamics.md) 细化 \(F_{ext}\) 与约束；[09 篇](./09_sim_tools_and_learning.md) 讨论仿真中触觉与力的对齐。

## 五、自适应控制（接 \(Y\theta\)）

当 \(\hat M,\hat C,\hat G\) 来自不精确 URDF，**自适应控制**在线更新 \(\hat\theta\)，使 \(\hat Y\hat\theta\) 逼近真模型。基础来自 [04 篇](./04_dynamics_equation_properties.md) 的线性参数化：

\[
\tau = Y(q,\dot q,\ddot q)\,\theta + \tau_{ext}
\]

### 自适应 CTC（概念）

控制律（示意，\(\tau_{ext}=0\)）：

\[
\tau = \hat Y(q,\dot q,\ddot q_r)\,\hat\theta + K_p e + K_d \dot e
\]

\[
\ddot q_r = \ddot q_d + \lambda \dot e + \Gamma e \quad (\text{参考加速度})
\]

参数更新律（梯度型 / MIT 规则）：

\[
\dot{\hat\theta} = \Gamma_\theta\, Y^\top(q,\dot q,\ddot q_r)\,s
\]

\(s\) 为滑动面或跟踪误差滤波量，\(\Gamma_\theta>0\) 为增益矩阵。**稳定性**依赖 \(Y\) 结构与 \(\dot M - 2C\) 反对称性（[04 篇](./04_dynamics_equation_properties.md)）：在持续激励下 \(\tilde\theta = \hat\theta - \theta\) 有界或收敛。

| 要点 | 说明 |
|------|------|
| 与辨识关系 | 离线 LS（[05 篇](./05_parameter_identification.md)）给初值；在线 RLS/自适应微调 |
| 基参数 | 只自适应**可观测**的基参数，避免冗余 \(\hat\theta\) 漂移 |
| 摩擦 | \(Y\theta\) 不含摩擦时，\(\hat\theta\) 会「吸收」摩擦误差 |
| 接触 | \(\tau_{ext}\neq 0\) 时更新律需修正或暂停，否则 \(\hat\theta\) 被接触力污染 |

自适应适合**慢变负载**（抓不同重物）或**模型系统偏差**；对突发碰撞与未建模柔性，仍需鲁棒项或阻抗兜底。

## 六、鲁棒 / 滑模（未建模动态）

**未建模动态**包括：摩擦未补偿、关节柔性、传动间隙、 \(\tau_{ext}\) 突变、 \(\Delta M = M - \hat M\)。**鲁棒控制**在已知有界扰动 \(\|\Delta\| \le \rho\) 下保证稳定；**滑模控制（SMC）** 用不连续切换项把误差压到**滑模面**上。

### 滑模直觉（关节空间）

定义滑动面：

\[
s = \dot e + \Lambda_s e, \quad e = q_d - q
\]

控制律（结构）：

\[
\tau = \hat M\,\ddot q_r + \hat C\,\dot q + \hat G + K s + \rho\,\mathrm{sgn}(s)
\]

\(\mathrm{sgn}(s)\) 项在模型误差与扰动有界时**强行**把 \(s \to 0\)；到达滑模面后误差指数收敛。**抖振（chattering）**：理想 \(\mathrm{sgn}\) 高频切换 → 用 \(\tanh(s/\epsilon)\) 或边界层代替。

| 方法 | 优点 | 缺点 |
|------|------|------|
| 鲁棒 \(H_\infty\) / \(L_2\) | 系统化处理有界不确定性 | 设计复杂，保守 |
| 滑模 \(\rho\,\mathrm{sgn}(s)\) | 对匹配扰动强 | 抖振、磨损、噪声敏感 |
| 阻抗 + 有界鲁棒 | 接触任务实用 | \(\rho\) 过大仍硬 |

**与 CTC / 自适应分工**：CTC 管标称非线性；自适应管**缓变**参数误差；滑模/鲁棒管**有界残差**与 \(\tau_{ext}\) 中可建模为扰动的部分。接触任务中纯滑模常与环境刚性冲突，**阻抗 + 小鲁棒项**更常见；强约束接触见 [08 篇](./08_contact_dynamics.md)。

## 七、与 `03` 控制链路的衔接

[03-机器人控制与坐标系基础](../03-机器人控制与坐标系基础.md) 从**系统视角**给出：坐标系 → 运动学 → **控制链路**（策略 → 底层 PID / 阻抗 / 力控）→ 观测与标定。该文 **§8.4 阻抗控制** 用「虚拟弹簧阻尼」直觉解释接触任务，**§8.5** 给出 VLA 任务与底层控制的粗略对应。本篇在同一仓库内做**动力学侧补全**：

| [03 篇](../03-机器人控制与坐标系基础.md) | 本篇（07） |
|------------------------------------------|------------|
| 阻抗 = 弹簧阻尼手感 | \(F = K\Delta x + D\Delta\dot x\) 与 \(\Lambda(x)\)、\(\tau=J^\top F\) 的方程来源 |
| 力控需要 F/T、wrench 闭环 | 混合 \(S\) 划分、导纳外环 |
| 接触任务靠阻抗兜底 | CTC 在 \(\tau_{ext}\neq 0\) 时失效 → 阻抗/混合/导纳 |
| 控制链路框图 | \(M,C,G\) 前馈在链路中的位置（CTC、操作空间律） |

阅读顺序建议：**03（链路 + 直觉）→ 04–06（方程与 \(\Lambda\)）→ 07（控制律）→ 08（接触）**。部署 VLA 时，策略输出仍落在 [03 篇](../03-机器人控制与坐标系基础.md) 的「笛卡尔增量 / 关节目标」接口上；底层是否启用本篇的阻抗/导纳参数，决定接触瞬间的力峰值与 Sim2Real 差距。

## 小结

- **基于模型控制**用 \(M,C,G\) 与 \(\Lambda(x)\) 做前馈，主线包括 CTC、混合、阻抗/导纳、自适应与鲁棒。
- **CTC**：\(\tau = M v + C\dot q + G\)，\(v = \ddot q_d + K_p e + K_d \dot e\)，反馈线性化；接触时需改力/位或阻抗。
- **混合控制**：选择矩阵 \(S\) 划分位控/力控子空间；法向力控 + 切向位控是典型模式。
- **阻抗**在力矩层设 \(K,D\)；**导纳**在力传感下修正 \(x_c\)；VTLA/触觉通过 \(\hat F\) 与 \(K,D\) 对齐 \(\tau_{ext}\)。
- **自适应**利用 \(Y\theta\) 与 \(\dot{\hat\theta} = \Gamma Y^\top s\)；**滑模**用 \(\rho\,\mathrm{sgn}(s)\) 对付有界未建模项，注意抖振。
- 与 [03 控制与坐标系](../03-机器人控制与坐标系基础.md) 的控制链路互补；接触力学见下一篇。
