## 一、每连杆 10 个惯性参数

每个刚体连杆的惯性可用 **10 个标量**完整描述（在已知连杆坐标系下）：

| 类别 | 个数 | 符号（常见记法） | 含义 |
|------|------|------------------|------|
| 质量 | 1 | \(m_i\) | 连杆质量 |
| 一阶矩 | 3 | \(h_i = m_i\, c_i\) 或 \(m_i c_{x,i}, m_i c_{y,i}, m_i c_{z,i}\) | 质心相对连杆坐标系原点的一阶矩（\(c_i\) 为质心位置） |
| 惯量张量 | 6 | \(I_{xx}, I_{yy}, I_{zz}, I_{xy}, I_{xz}, I_{yz}\) | 相对质心的对称惯量张量独立元素 |

**为什么是 10 个**：\(3\times 3\) 对称惯量矩阵有 6 个独立元，加上 1 个质量与 3 个质心一阶矩，共 10。在回归矩阵 \(Y\) 中，这些量往往以**组合形式**出现（如 \(m_i c_{x,i}\) 而非单独的 \(c_{x,i}\)），因为 \(\tau\) 对 \((m, mc, I)\) 线性，对 \((m, c)\) 单独则非线性。

\(n\) 关节、\(N\) 连杆机械臂，朴素计数为 \(10N\) 个惯性参数；实际独立个数常**小于** \(10N\)，原因见第四节基参数。

与 [04 篇](./04_dynamics_equation_properties.md) 的接口：对任意 \((q,\dot q,\ddot q)\)，

\[
Y(q,\dot q,\ddot q)\,\theta = M(q)\ddot q + C(q,\dot q)\dot q + G(q)
\]

\(\theta\) 即各连杆惯性参数的某种排列；\(Y\) 的每一列对应「该参数取 1、其余为 0 时产生的关节力矩向量」。URDF 中的 `<mass>`、`<origin xyz>`（质心）、`<inertia>` 应与 \(\theta\) 的物理含义一致；标定目标往往是让模型 \(\theta\) 逼近真机。

## 二、为什么需要激励轨迹

若只在**静止**或**小范围重复**运动下采集数据，回归矩阵 \(Y\) 的列往往**近似线性相关**——不同惯性参数对 \(\tau\) 的贡献无法区分。数学上，堆叠后的 \(Y_{stack}\) **不满秩**或条件数极差，最小二乘解 \(\hat\theta\) 不唯一、对噪声极度敏感。

**激励轨迹（excitation trajectory）** 的目的：在工作空间内做**充分丰富**的运动，使各惯性参数在不同 \((q,\dot q,\ddot q)\) 组合下都有可观贡献，让 \(Y_{stack}\) 列满秩（或条件数可接受）。

| 激励目的 | 希望激发的参数/效应 |
|----------|---------------------|
| 多姿态、竖直/水平伸展 | 重力项 \(G(q)\) 中的质量、质心 |
| 加速/减速段 | \(M\ddot q\) 中的质量与惯量 |
| 多关节同时运动 | 科氏/离心 \(C\dot q\) 与惯量耦合 |
| 覆盖工作空间边界 | 避免只在「舒适区」辨识 |

**持续激励（persistent excitation, PE）**：轨迹产生的回归信息足够丰富，使参数可辨识。工程上常用 **Fourier 级数**或 **最小激励轨迹** 离线优化：在满足关节限位、速度/力矩约束下，最大化 \(Y_{stack}\) 的最小奇异值或降低条件数 \(\kappa(Y_{stack})\)。

直觉：辨识不是「随便跑一圈」，而是给系统做**体检动作**——每种参数都要在数据里「露过面」，否则 \(Y\theta\) 再漂亮，\(\hat\theta\) 也不可信。

## 三、最小二乘辨识流程

在忽略或已扣除 \(\tau_{ext}\)、并假设摩擦单独建模的前提下，单时刻有

\[
\tau = Y(q,\dot q,\ddot q)\,\theta
\]

对 \(K\) 个采样时刻堆叠（\(Y_k\) 为第 \(k\) 步的回归矩阵行块）：

\[
\begin{bmatrix} \tau_1 \\ \tau_2 \\ \vdots \\ \tau_K \end{bmatrix}
=
\begin{bmatrix} Y_1 \\ Y_2 \\ \vdots \\ Y_K \end{bmatrix}
\theta
\quad\Leftrightarrow\quad
\tau_{stack} = Y_{stack}\,\theta
\]

**批处理最小二乘（batch LS）**：

\[
\hat\theta = \arg\min_\theta \|\tau_{stack} - Y_{stack}\,\theta\|_2^2
= (Y_{stack}^\top Y_{stack})^{-1} Y_{stack}^\top \tau_{stack}
\]

（\(Y_{stack}\) 列满秩时；否则用伪逆或正则化，见下。）

### 标准工程流程

| 步骤 | 内容 |
|------|------|
| 1. 建模 | 固定 \(Y\theta\) 结构；明确 \(\theta\) 与 URDF 字段对应关系 |
| 2. 设计轨迹 | 激励轨迹 + 关节/力矩约束；离线检查 \(Y_{stack}\) 秩 |
| 3. 采集 | 真机或高精度仿真记录 \(q,\dot q,\ddot q,\tau\)（或电流估力矩） |
| 4. 构造 \(Y_{stack}\) | Pinocchio `computeJointTorqueRegressor` 等；\(\ddot q\) 常由 \(\dot q\) 数值微分 + **低通滤波** |
| 5. 求 \(\hat\theta\) | LS / 加权 LS / 岭回归 \(\hat\theta = (Y^\top W Y + \lambda I)^{-1} Y^\top W \tau\) |
| 6. 验证 | **独立验证轨迹**上比较 \(\tau_{meas}\) 与 \(Y\hat\theta\)；报告 RMSE |

**在线辨识**可用递推最小二乘（RLS）或自适应律 \(\dot{\hat\theta} = \Gamma Y^\top(\tau - Y\hat\theta)\)（与 07 篇自适应控制衔接）；离线批处理更易调试、更适合首次 URDF 标定。

**注意**：辨识对象是 **\(Y\theta\) 中的 \(\theta\)**，不是直接对 \(M,C,G\) 矩阵元素做黑盒拟合；结构来自拉格朗日，保证与控制器用的模型一致。

## 四、基参数：不可观与耦合

并非 \(10N\) 个朴素参数都能从任意轨迹上单独估出。存在**参数耦合**：某些线性组合在所有可达运动下产生相同的 \(\tau\)，即不可观。

**基参数（base parameters）**：能表示系统全部可行动力学、且**维数最小**的参数向量 \(\theta_b\)。冗余参数可合并进基参数，或在任意轨迹上不可区分。

求法（概念上）：对大量 \((q,\dot q,\ddot q)\) 采样堆叠 \(Y_{stack}\)，对 \(Y_{stack}^\top Y_{stack}\) 或 \(Y_{stack}\) 做 **SVD**：

- 奇异值显著大于零的列空间 → 基参数方向；
- 近零奇异值对应的方向 → 不可观组合（任意扰动不改变拟合 \(\tau\)）。

| 现象 | 含义 |
|------|------|
| 两参数始终成比例出现在 \(Y\) 中 | 只能辨识其和或比，不能单独辨识 |
| 末端负载与最后一连杆质量耦合 | 需已知负载或加约束才能拆开 |
| 仅辨识重力项 | 往往只需与 \(G(q)\) 相关的基参数子集 |

工程实践：**不强行估计全部 \(10N\) 个**，而用 SVD/符号化简得到基参数，再 LS 估计 \(\hat\theta_b\)，最后映射回 URDF 或只更新控制用组合量（如 \(G(q)\) 前馈所需项）。辨识论文中的「最小参数集」即基参数。

## 五、工程注意：摩擦、关节柔性、传感器噪声

理想模型 \(\tau = Y\theta\) 在真机上几乎总是**残差显著**。主要来源：

### 摩擦

库仑 + 粘滞摩擦常见写法：

\[
\tau_f = F_c\,\mathrm{sign}(\dot q) + F_v\,\dot q
\]

\(\mathrm{sign}(\dot q)\) 在 \(\dot q \approx 0\) 时不连续，且与 \(Y\theta\) **非线性可分**。处理策略：

- 单独辨识摩擦参数（扩展回归或分步法）；
- 低速段剔除或单独建模；
- 控制侧用摩擦补偿查表，而非全塞进 \(\theta\)。

### 关节柔性

减速器弹性、连杆弯曲使「电机侧 \(q\)」与「连杆侧 \(q\)」不一致，\(Y(q,\dot q,\ddot q)\) 基于刚性模型，残差随负载与速度变大。辨识只能拟合**等效**参数；高精度力控需加柔性项或用关节扭矩传感器在连杆侧测量。

### 传感器噪声与微分

| 问题 | 影响 | 常见处理 |
|------|------|----------|
| \(\tau\) 由电流估计 | 比例误差、偏置、量化 | 校准力矩常数；加权 LS |
| \(\ddot q\) 数值微分 | 噪声放大进 \(Y\) | 对 \(\dot q\) 滤波后再微分；或卡尔曼/样条平滑 |
| 编码器量化 | \(\dot q\) 台阶 | 低速段信噪比差，避免仅用低速数据 |
| 未建模 \(\tau_{ext}\) | 接触时 \(\tau\) 含外力 | 辨识时保证无接触或显式扣除 |

**验证比拟合更重要**：在**未参与训练**的轨迹上算 \(\| \tau - Y\hat\theta \|\)；若验证 RMSE 远大于训练集，说明过拟合、激励不足或摩擦/柔性未建模。工业部署常优先标定 **\(G(q)\)**（重力补偿）与主要连杆惯量，摩擦单独补偿，而非追求全参数完美。

## 小结

- 每连杆 **10 个**惯性参数（\(m\)、3 个一阶矩、6 个惯量元）；经 \(Y\theta\) 与 [04 篇](./04_dynamics_equation_properties.md) 的 \(M,C,G\) 结构对接。
- **激励轨迹**使 \(Y_{stack}\) 满秩或条件数良好；静止与小范围运动不足以辨识。
- **批处理最小二乘**：堆叠 \(\tau_{stack} = Y_{stack}\theta\)，求 \(\hat\theta\)；\(\ddot q\) 与 \(\tau\) 需滤波与验证轨迹交叉检验。
- **基参数**是最小可辨识集；SVD 揭示不可观耦合，勿盲目估计全部 \(10N\) 个参数。
- 真机需面对**摩擦、柔性、噪声**；常与「只标重力/主要惯量 + 摩擦补偿」的分步策略配合。
