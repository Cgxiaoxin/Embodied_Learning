## 一、为什么要任务空间动力学

**任务空间**（又称操作空间、笛卡尔空间）以末端执行器位姿 \(x\)（位置 + 姿态）或 twist 为状态，而非关节角 \(q\)。动机：

| 场景 | 关节空间不便之处 | 任务空间优势 |
|------|------------------|--------------|
| 力控 / 接触 | 接触力沿法向，在笛卡尔系直观 | 直接指定 \(F_n, F_t\) 或期望接触力 |
| 阻抗控制 | 希望末端「像弹簧」\(F = K\Delta x + D\Delta\dot x\) | 刚度 \(K\)、阻尼 \(D\) 在 \(x\) 中有物理意义 |
| 轨迹跟踪 | IK 多解、奇异 | 在 \(x\) 跟踪，关节由冗余度或 null-space 处理 |
| VLA / 示教 | 策略常输出末端增量 \(\Delta x\) | 与 \(\dot x = J\dot q\) 自然衔接 |

[03 控制与坐标系](../03-机器人控制与坐标系基础.md) 已介绍阻抗概览与 \(\tau = J^\top F\) 的静力映射；那只是**无加速度**时的特殊情形。完整动力学里，末端加速度 \(\ddot x\) 与力 \(F\) 之间还有**惯量**——由 \(\Lambda(x)\) 描述。力控增益、阻抗参数整定若忽略 \(\Lambda\)，会出现「同样 \(K\) 在不同位形下手感完全不同」的现象。

## 二、关节空间 ↔ 任务空间映射（via \(J\)）

记末端 twist \(x \in \mathbb{R}^m\)（通常 \(m=6\)：3 线速度 + 3 角速度，或按控制器选 3/6 维子集）。[01 篇](./01_kinematics_review.md) 的两条核心接口：

**速度映射**（一阶）：

\[
\dot x = J(q)\,\dot q
\]

**静力 / 拟静力映射**（虚功对偶）：

\[
\tau = J^\top(q)\,F
\]

其中 \(F\) 为末端 **wrench**（力 + 力矩，与 \(\dot x\) 维数一致）。\(J \in \mathbb{R}^{m\times n}\)，\(n\) 为关节数。

**加速度层**（对 \(\dot x = J\dot q\) 求导，假设 \(J\) 随 \(q(t)\) 变化）：

\[
\ddot x = J(q)\,\ddot q + \dot J(q,\dot q)\,\dot q
\]

\(\dot J\,\dot q\) 为**科氏项在任务空间的体现**（与关节空间 \(C\dot q\) 对应）。任务空间动力学里常把 \(\dot J\dot q\) 吸收进 \(\mu(x,\dot x)\) 等非线性项。

**冗余臂**（\(n>m\)）：同一 \(\dot x\) 对应无穷多 \(\dot q\)；\(J\) 非方阵，需伪逆 \(J^\dagger\) 或 null-space 投影，\(\Lambda\) 的定义需限定在**可操作子空间**上（下文默认 \(J\) 行满秩，\(m\le n\)）。

## 三、操作空间惯量 \(\Lambda(x) = (J M^{-1} J^\top)^{-1}\)

### 从关节方程出发

无外力时关节空间：

\[
M(q)\,\ddot q + C(q,\dot q)\,\dot q + G(q) = \tau
\]

设 \(\tau = J^\top F\)（纯任务空间广义力，或把 \(G\) 等已补偿项略去看局部关系），且暂忽略 \(\dot J\dot q\)，则 \(\ddot q = M^{-1}(J^\top F - C\dot q - G)\)。代入 \(\ddot x \approx J\ddot q\)：

\[
\ddot x \approx J M^{-1} J^\top F - J M^{-1}(C\dot q + G) + \cdots
\]

定义**操作空间惯量矩阵**（Khatib 操作空间形式）：

\[
\boxed{
\Lambda(x) \triangleq \big( J(q)\, M(q)^{-1}\, J^\top(q) \big)^{-1}
}
\]

在 \(J\) 行满秩、\(M\) 正定时，\(J M^{-1} J^\top\) 正定，\(\Lambda\) 存在且对称正定。

**等价写法**（便于实现）：\(\Lambda = (J^{-\top} M J^{-1})^{-1}\) 在非冗余情形；冗余时常用 \(J^\dagger = M^{-1} J^\top \Lambda\) 相关的投影形式，但上式 boxed 定义是标准**可操作空间惯量**。

### 物理直觉

| 量 | 关节空间 | 任务空间 |
|----|----------|----------|
| 广义惯量 | \(M(q)\) | \(\Lambda(x)\) |
| 「同样加速度要多大力」 | \(\tau \sim M\ddot q\) | \(F \sim \Lambda\ddot x\) |
| 位形依赖 | 手臂蜷缩/伸展改变 \(M\) | 同样改变末端「手感」轻重 |

**直觉 1**：\(\Lambda\) 是「把关节惯量 \(M\) 通过 \(J\) **投影**到末端 twist 方向后，再取对偶逆」。某笛卡尔方向若对应 \(J\) 的小奇异值方向，同样 \(\ddot x\) 需要更大关节加速度 → \(\Lambda\) 在该方向**更大**（更难加速）。

**直觉 2**：\(\Lambda^{-1} = J M^{-1} J^\top\) 描述「单位末端 wrench \(F\) 在约束子空间内产生的 \(\ddot x\) 趋势」的逆关系；\(\Lambda\) 则是「产生单位 \(\ddot x\) 需要多大 \(F\)」。

**奇异位形**：\(\det J \to 0\) 时 \(J M^{-1} J^\top\) 近奇异，\(\Lambda\) **发散**——某些末端方向瞬时无法加速，或关节速度需求爆炸。力控在奇异附近也会放大 \(F\)；与 [01 篇](./01_kinematics_review.md) 的奇异讨论一致。

### 完整任务空间方程（结构）

引入任务空间科氏/重力项 \(\mu(x,\dot x)\)、\(p(x)\)，标准**操作空间动力学**可写为：

\[
\Lambda(x)\,\ddot x + \mu(x,\dot x) + p(x) = F + F_{ext}
\]

其中 \(F_{ext}\) 为环境接触等外力（wrench）；\(\mu\) 含 \(\dot J\dot q\) 与 \(C\dot q\) 的映射；\(p\) 含 \(G\) 的映射。具体分解依赖选取的 \(J\) 坐标系（世界系 / 工具系）；[07 篇](./07_dynamics_based_control.md) 在控制器设计时再固定一种约定。

本篇重点记住 **\(\Lambda\) 的定义与位形依赖**；实现上可用 \(M\) 的 Cholesky 分解配合 \(J\) 求 \(\Lambda\)，避免显式求 \(M^{-1}\) 再求大矩阵逆（数值上常用 LDLT / 可操作空间算法）。

## 四、与末端力、加速度的关系

### 准静态：\(\tau = J^\top F\)

当 \(\ddot q \approx 0\)、\(\dot q \approx 0\) 时，\(M\ddot q + C\dot q \approx 0\)，若重力已补偿则 \(\tau \approx J^\top F\)。这是**纯力控**映射：在末端施加 wrench \(F\)，关节只需克服该静力。不含 \(\Lambda\)，因为无加速度。

### 含加速度：\(F\) 与 \(\ddot x\)

在 \(\mu, p\) 已知或已补偿时：

\[
F \approx \Lambda(x)\,\ddot x + \text{（已补偿项）}
\]

即：要在末端产生加速度 \(\ddot x\)，需施加与 \(\Lambda\) 成正比的惯性力。**同样 \(\ddot x_d\)**，手臂伸直（\(M\) 大、\(J\) 几何不利）时所需 \(|F|\) 可能远大于蜷缩构型——阻抗增益 \(K,D\) 若固定，闭环刚度会随 \(\Lambda\) 隐式变化。

### 与关节力矩的闭合关系

控制律常写 \(\tau = J^\top F + \tau_0\)，其中 \(F\) 由任务空间 PD/阻抗产生，\(\tau_0\) 为重力补偿或 null-space 关节项。代入 \(M\ddot q + C\dot q + G = \tau\) 并经 \(J\) 投影，可得含 \(\Lambda\) 的 \(\ddot x\) 方程——这是 **操作空间逆动力学** 与 **阻抗控制** 的方程基础。

**与参数辨识的衔接**：[05 篇](./05_parameter_identification.md) 标定的 \(\theta\) 进入 \(M\)；\(M\) 误差直接变为 \(\Lambda\) 误差，进而影响力控前馈与阻抗「手感」。标定后应在多个位形检查 \(\Lambda\) 或末端加速度响应。

## 五、为第 07 章铺垫

[07 基于动力学的控制](./07_dynamics_based_control.md) 将在此基础上展开：

| 主题 | 与 \(\Lambda, J\) 的关系 |
|------|--------------------------|
| **计算力矩** | 关节空间 \(M,C,G\) 反馈线性化；可先算任务空间期望 \(\ddot x_d\) 再映回 \(\ddot q_d\) |
| **操作空间控制** | 在 \(\Lambda\ddot x + \mu + p = F\) 上设计 \(F = \Lambda\ddot x_d + \cdots\) |
| **阻抗 / 导纳** | 期望 \(F = K\Delta x + D\Delta\dot x\)；\(\Lambda\) 决定「同样 \(K\)」下的实际加速度响应 |
| **力/位混合** | 选择矩阵在任务空间划分力控子空间与位控子空间；仍依赖 \(J, J^\top\) |
| **自适应** | \(\hat\theta\) 更新改变 \(\hat M\)，从而改变 \(\hat\Lambda\) |

读者从本篇带走三个对象：**\(J\)**（速度/静力接口）、**\(\Lambda = (J M^{-1} J^\top)^{-1}\)**（任务空间惯量）、**完整操作空间方程** \(\Lambda\ddot x + \mu + p = F\)。07 篇把它们变成可部署的控制律，并与 [03 控制与坐标系](../03-机器人控制与坐标系基础.md) 中的阻抗链路对齐。

## 小结

- 力控、阻抗与末端策略输出都在**任务空间**表述；需把关节 \(M,C,G\) 映到 \(x\)。
- **\(\dot x = J\dot q\)**、**\(\tau = J^\top F\)** 是一阶与静力接口；加速度层有 \(\ddot x = J\ddot q + \dot J\dot q\)。
- **操作空间惯量** \(\Lambda(x) = (J M^{-1} J^\top)^{-1}\)：对称正定（\(J\) 满秩时），刻画「末端加速度与 wrench 的惯性耦合」，随位形变化，奇异处发散。
- 完整形式 \(\Lambda\ddot x + \mu + p = F\)；准静态时退化为 \(J^\top F\)。
- [07 篇](./07_dynamics_based_control.md) 在此基础上做计算力矩、阻抗与力位混合；辨识得到的 \(M\) 质量决定 \(\Lambda\) 可信度。
