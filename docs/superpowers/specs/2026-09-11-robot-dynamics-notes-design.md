## 1. 背景与目标

运控转向具身智能 / VLA（尤其是视触觉、接触力相关的 VTLA）时，刚体动力学与接触动力学是关键基础。本系列补齐仓库中尚缺的「动力学」理论层，使读者能：

- 从运动学接口平滑进入 \(M\ddot q+C\dot q+G=\tau+\tau_{ext}\)
- 理解牛顿-欧拉与拉格朗日两条建模路径及其工程取舍
- 把任务空间动力学、阻抗/力控、接触模型接到仿真工具与学习方法（Sim2Real、WBC、触觉估力）

**非目标（本轮不做）**：面试专题 Q&A、新 SVG 插图、改写 `03-机器人控制与坐标系基础` 正文、单独开 VTLA 专篇。

| 文件 | 写什么 | 不写 / 外链 |

### 交叉引用约定

- **对内**：`dynamics/` 内相对路径互链（尤其 `07`↔`08`、`04`↔`05`）
- **对外**：运动学/控制 → `../03-...`；VLA/RL → `../01`、`../02`；工程 → `../../projects/...`
- **VTLA/视触觉**：在 `00`、`07`、`08`、`09` 各用一小段点明与方向的关系，不另开专篇

### 文风模板（每篇）

1. 文首元信息：`类型 · 层级 · 状态 · 更新 · 关联`
2. 导读短段 + 目录
3. 正文：直觉 → 标准形式 / 推导骨架 → 工程含义
4. 文末：小结 + 建议下一篇
